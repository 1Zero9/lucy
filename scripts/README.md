# Scripts

- `check-prereqs.sh` — checks local tooling.
- `first-run.sh` — installs dependencies and verifies Wrangler login.
- `create-infra.sh` — interactively creates/lists D1/R2 resources; no deletes.
- `list-infra.sh` — lists current D1/R2 resources.
- `migrate-production.sh` — guarded production migration command.

The scripts intentionally do not automate destructive actions.
