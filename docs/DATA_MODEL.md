# LUCY Data Model

The first migration implements only foundation entities. Future objects are documented here so naming remains consistent.

## Foundation

- `users`
- `user_settings`
- `workspaces`
- `periods`
- `modules`
- `notes`
- `note_versions`

## Later

- `tags`
- `note_tags`
- `stickies`
- `tasks`
- `attachments`
- `research_items`
- `drawings`
- `flashcards`

## General rules

- IDs are text UUIDs generated by trusted application code.
- Timestamps are UTC ISO-8601 text.
- Important user content supports soft deletion.
- Owner-scoped indexes are required.
- Database constraints complement application validation.
