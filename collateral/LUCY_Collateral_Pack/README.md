# LUCY Collateral Pack

Contents:
- `LUCY_STYLE_GUIDE.md` — complete product/UI style guide
- `brand/` — app icon master and common PWA/app sizes
- `icons/svg/` — individual Lucide-aligned SVG icons
- `icons/png/` — individual raster preview icons
- `banners/` — alert/status banner assets
- `tokens/` — CSS and JSON design tokens
- `reference/` — approved UI style board

The SVG icon files are the canonical UI icon assets. The PNG icon folder is provided for quick visual/reference use.
